# Sesiones Didácticas de Kubernetes (K8s)

## 📋 Descripción del Proyecto
Este proyecto contiene sesiones didácticas completas para aprender Kubernetes desde cero hasta nivel avanzado.

## 🎯 Objetivos de Aprendizaje
- Comprender los conceptos fundamentales de Kubernetes
- Aprender a desplegar aplicaciones en K8s
- Dominar la gestión de recursos y servicios
- Implementar CI/CD con Kubernetes
- Resolver problemas comunes en producción

## 📚 Estructura de Sesiones

### Sesión 1: Fundamentos de Kubernetes
- [ ] Introducción a contenedores y Docker
- [ ] Arquitectura de Kubernetes
- [ ] Componentes principales (Master y Worker nodes)
- [ ] Conceptos básicos: Pods, Services, Deployments

### Sesión 2: Primeros Pasos
- [ ] Instalación de kubectl
- [ ] Configuración de cluster local (minikube/kind)
- [ ] Comandos básicos de kubectl
- [ ] Primer deployment

### Sesión 3: Gestión de Recursos
- [ ] Pods y su ciclo de vida
- [ ] ReplicaSets y Deployments
- [ ] Services y networking
- [ ] ConfigMaps y Secrets

### Sesión 4: Almacenamiento
- [ ] Volumes y PersistentVolumes
- [ ] StorageClasses
- [ ] Configuración de almacenamiento
- [ ] Backup y restauración

### Sesión 5: Networking Avanzado
- [ ] Ingress controllers
- [ ] Network policies
- [ ] Service mesh (Istio)
- [ ] Load balancing

### Sesión 6: Seguridad
- [ ] RBAC (Role-Based Access Control)
- [ ] Service accounts
- [ ] Security contexts
- [ ] Pod security policies

### Sesión 7: Monitoreo y Logging
- [ ] Prometheus y Grafana
- [ ] ELK stack
- [ ] Métricas y alertas
- [ ] Troubleshooting

### Sesión 8: CI/CD con Kubernetes
- [ ] GitOps con ArgoCD
- [ ] Jenkins en K8s
- [ ] GitHub Actions
- [ ] Deployment strategies

### Sesión 9: Operaciones Avanzadas
- [ ] Auto-scaling
- [ ] Resource quotas
- [ ] Taints y tolerations
- [ ] Node affinity

### Sesión 10: Proyecto Final
- [ ] Aplicación completa en producción
- [ ] Best practices
- [ ] Troubleshooting real
- [ ] Optimización de costos

## 🛠️ Herramientas Necesarias
- Docker Desktop
- kubectl
- minikube o kind
- IDE (VS Code con extensiones de K8s)
- Helm (opcional)

## 🚀 Cómo Usar Este Proyecto
1. Clona este repositorio
2. Sigue las sesiones en orden
3. Completa los ejercicios prácticos
4. Revisa los ejemplos de código

## 📝 Notas
- Cada sesión incluye teoría, ejercicios prácticos y ejemplos de código
- Los archivos YAML están listos para usar
- Incluye scripts de automatización para facilitar el aprendizaje
